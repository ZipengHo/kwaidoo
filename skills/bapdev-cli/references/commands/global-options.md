# 全局选项

以下选项是 CLI 底层支持的全局参数。技能默认优先使用 `.bapdev-cli` 与全局会话信息，不建议把这些参数当成常规配置入口：

| 选项 | 说明 |
|------|------|
| `--uri <uri>` | BAP 服务器 URI 地址 |
| `-u, --user <user>` | 用户名 |
| `-p, --password <password>` | 密码 |
| `--project <project>` | 项目标识 |
| `-c, --config <config>` | 配置文件路径 |
| `-h, --help` | 显示帮助信息 |
| `-V, --version` | 显示版本信息 |
