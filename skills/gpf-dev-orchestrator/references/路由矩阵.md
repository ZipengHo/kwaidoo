# GPF 开发路由矩阵

## 路由目标

- `gpf-cloud-cell`：Cell、Service Cell、资源 Cell、异步 Cell、云配置、云 UDF、远程联调
- `gpf-api-call`：`IUserMgr`、`IRoleMgr`、`IFormMgr`、用户角色组织、表单模型、`Cnd`、`ResultSet`
- `gpf-http-interface`：`@RequestMapping`、GET/POST、参数绑定、文件上传下载、JWT、SSE、拦截器
- `gpf-rule-function`：规则函数、`@ClassDeclare`、`@MethodDeclare`、环境变量、回调、路由计算、身份匹配、动态权限
- `gpf-permission-matrix`：权限领域扩展资料，用于补充鉴权语义、授权语义、身份对象和按钮/字段权限边界
- `gpf-microservice`：TinyService、服务路由、服务追踪、服务钩子、跨服务调用

## 冲突判定

- 如果最终产物是对外 HTTP 接口，优先 `gpf-http-interface`
- 如果最终产物是规则函数代码，优先 `gpf-rule-function`
- 如果最终产物是规则函数中的权限控制逻辑，仍优先 `gpf-rule-function`，并补充 `gpf-permission-matrix`
- 如果最终产物是权限模型、授权边界或矩阵规则设计，优先 `gpf-permission-matrix`
- 如果最终产物是微服务接口或跨服务调用逻辑，优先 `gpf-microservice`
- 如果最终产物是 Cell 实现或服务编排，优先 `gpf-cloud-cell`
- 如果最终产物是对用户、角色、表单、数据模型的直接操作代码，优先 `gpf-api-call`

## 输出要求

- 输出命中的技能名称
- 输出 1 至 3 个命中依据
- 如果无法唯一命中，先说明需要补充的最小信息，再给出当前最可能的技能
