# GPF 开发总入口源码类索引导航

## 使用规则

- 总入口技能不直接定义具体源码类事实
- 只要需求已经落到真实类、接口、包路径或框架基类，必须转到命中专项技能的源码类索引继续核实

## 专项技能索引入口

- 基础 API 调用：`../gpf-api-call/references/源码类索引.md`
- 云开发 Cell：`../gpf-cloud-cell/references/源码类索引.md`
- HTTP 接口：`../gpf-http-interface/references/源码类索引.md`
- 规则函数：`../gpf-rule-function/references/源码类索引.md`
- 权限矩阵：`../gpf-permission-matrix/references/源码类索引.md`
- 微服务：`../gpf-microservice/references/源码类索引.md`

## 路由约束

- 在未命中专项技能前，不得输出任何现有类的确定包路径和接口签名
- 如果用户只给了类名线索，总入口阶段只保留线索，不补全实现细节
