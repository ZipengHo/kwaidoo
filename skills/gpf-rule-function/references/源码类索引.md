# GPF 规则函数源码类索引

## 使用规则

- 本索引用于定位规则函数开发中常见、但必须先核实的现有注解和上下文类型
- 当前技能已内置高频注解和部分环境变量类型的最小必要源码快照
- 一旦需要在输出中给出现有注解、接口、环境变量类型或上下文对象的真实包路径与签名，必须先读取这里登记的源码快照；未收敛类型再回到工程源码核实

## 仍需从工程源码核实的类型

- `WfeStepOperator`
- `feContext`
- 规则函数相关基类或接口
- 其他未收敛的环境变量相关类型

## 常见核实场景

- 需要确认注解属性名、必填项和默认行为
- 需要确认规则函数方法签名、返回值和上下文入参
- 需要确认某个环境变量到底来自注解声明还是上下文对象

## 输出约束

- 未核实前，不得补全注解包路径和属性列表
- 未核实前，不得把示例方法签名写成现有工程唯一标准
- 对 `WfeStepOperator`、`feContext` 等当前未收敛类型，只能标注“待从源码核实”
