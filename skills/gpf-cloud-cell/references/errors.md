# GPF 云开发 Cell 常见错误

## 联调不生效

常见原因：

- 没有通过工厂获取
- 包结构不符合约定
- 目标类型选错

## 资源泄漏

常见原因：

- `doStopService()` 未关闭线程池
- 连接或缓存未清理

## 资源 Cell 使用方式错误

常见原因：

- 把资源 Cell 当作服务 Cell 用 `Cells.get()` 获取
- 创建资源后没有显式关闭
- 直接跨边界传递文件流、连接等不可序列化对象

## 配置不生效

常见原因：

- 配置类未绑定
- 默认值和外部配置覆盖关系未讲清

## 异步模型选错

常见原因：

- 使用了 `CompletableFuture`
- 返回类型不是 `IPromise`
- 异步任务太快完成，调用方尚未挂接消费者

## 预加载使用过度

常见原因：

- 明明只是普通查询逻辑，却实现了 `CellPreloadIntf`
- 在预加载启动逻辑里初始化了不必要的大资源

## UDF 编译失败

常见原因：

- UDF 互相引用
- 把复杂服务化逻辑写进 UDF
