# GPF 云开发资料索引

## 推荐读取顺序

1. `overview.md`
2. `core-concepts.md`
3. `workflow.md`
4. `patterns.md`
5. `errors.md`
6. `checklist.md`

## 按任务选资料

- 判断 Cell 类型：读取 `overview.md`
- 判断工厂、包结构、配置、UDF 约束：读取 `core-concepts.md`
- 新增或修改代码：读取 `workflow.md` 和 `patterns.md`
- 排错：读取 `errors.md`
- 输出前自检：读取 `checklist.md`
- 需要确认服务 Cell、预加载接口或配置服务定义：先读 `源码类索引.md`，再按需读取 `assets/source/`

## 示例资产

- 技能根目录下的 `assets/examples/basic_cell.java`
- 技能根目录下的 `assets/examples/basic_service_cell.java`
- 技能根目录下的 `assets/examples/service_cell_with_preload.java`
- 技能根目录下的 `assets/examples/async_service_cell.java`
- 技能根目录下的 `assets/examples/config_service_cell.java`
- 技能根目录下的 `assets/examples/resource_cell.java`

## 源码入口

- 源码类索引：`源码类索引.md`
- 源码快照目录：`assets/source/`
- 当前已收敛服务 Cell 生命周期、预加载接口和配置服务相关的最小必要源码；`Cells`、`BasicServiceCell` 等底层基类若仍未收敛，不能自行补路径

## 按 Cell 类型选示例

- 普通 Cell：读取 `assets/examples/basic_cell.java`
- 服务 Cell：读取 `assets/examples/basic_service_cell.java`
- 预加载服务 Cell：读取 `assets/examples/service_cell_with_preload.java`
- 异步服务 Cell：读取 `assets/examples/async_service_cell.java`
- 配置绑定服务 Cell：读取 `assets/examples/config_service_cell.java`
- 资源 Cell：读取 `assets/examples/resource_cell.java`

## 按问题选示例

- 判断该用哪种 Cell：先读 `overview.md`
- 判断 `Cells.get()` 和 `new` 的边界：读 `core-concepts.md`
- 需要缓存、线程池、生命周期模板：读 `assets/examples/basic_service_cell.java`
- 需要系统启动即加载：读 `assets/examples/service_cell_with_preload.java`
- 需要异步返回：读 `assets/examples/async_service_cell.java`
- 需要云配置绑定：读 `assets/examples/config_service_cell.java`
- 需要资源句柄封装与关闭：读 `assets/examples/resource_cell.java`
