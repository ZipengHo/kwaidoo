# GPF 云开发 Cell 执行流程

## 新增 Cell

1. 判断是普通、服务还是资源 Cell
2. 确定接口和实现的包结构
3. 确定是否需要配置类
4. 选择最接近的模板
5. 补齐启动、停止、异常和资源处理
6. 如果涉及异步、预加载、配置或资源句柄，补充对应约束
7. 说明调用方式与联调方式

## 修改现有 Cell

1. 先保留已有接口契约
2. 判断问题在类型选择、配置、生命周期还是资源使用
3. 对照 `assets/examples/` 选择最近似模式
4. 在最小改动下修复
5. 说明是否会影响联调、缓存、配置覆盖或并发行为

## 排障

1. 联调不生效：先查获取方式和包结构
2. 内存增长：先查 `doStopService`
3. 配置不生效：先查配置绑定和默认值
4. 异步返回异常：先查是否误用 `CompletableFuture`
5. 云端编译失败：先查 UDF 互相依赖
