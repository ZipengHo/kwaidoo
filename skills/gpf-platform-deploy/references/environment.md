# 环境要求

## 基线要求

- JDK：`1.8`
- 数据库：`PostgreSQL 9.3 及以上`

## 部署前至少确认

- `JAVA_HOME` 已正确指向 JDK 1.8
- 启动脚本执行环境能访问 `$JAVA_HOME/bin/java`
- PostgreSQL 版本满足 `9.3+`
- 数据库连接地址、用户名、密码可用于 `starter.xml` 或 `agent_starter.xml` 中的 DAO 配置

## 使用约束

- 如果用户当前环境版本低于上述基线，应先指出环境不满足，再继续讨论配置或启动步骤
- 如果用户只问部署条件，优先回答本文件内容，不必展开具体配置细节
