# GPF 基础 API 总览

## 五类核心管理器

### `IUserMgr`

适用：

- 用户创建
- 用户查询
- 用户更新

### `IRoleMgr`

适用：

- 角色、组织关系
- 角色挂载
- 权限关联

### `IFormMgr`

适用：

- 表单数据
- 字段取值
- 表单创建与更新
- 查询分页

### `IPDFRuntimeMgr`

适用：

- 流程发起与提交流程节点表单
- 查询流程表单列表和流程实例
- 操作流程实例状态

### `IBackupService`

适用：

- 表单 Excel 或 Json 导出导入
- 流程表单 Excel 导出与批量提交
- 模型、流程、数据包备份编排

## 常见伴随能力

- `Cnd` 条件构造
- `ResultSet` 分页结果
- 字段名称与字段编码转换
- 事务提交
- `PDCForm`、`PDFForm` 等流程运行对象
