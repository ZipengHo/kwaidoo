## 按任务选资料

- 判断管理器和对象：读取 `overview.md`
- 判断模型、字段、事务和分页：读取 `core-concepts.md`
- 判断真实可用操作面：读取 `manager-api.md`
- 判断实体与结果对象：读取 `entity-models.md`
- 判断 `Form` / `TableData` 什么时候用字段名、什么时候用系统常量：读取 `system-fields.md`
- 快速判断字段名、字段编码、系统常量怎么选：读取 `field-decision-table.md`
- 判断某个实体什么时候看示例、该看哪个示例：读取 `entity-examples.md`
- 贴近仓库真实调用方式：读取 `source-patterns.md`
- 生成代码：读取 `workflow.md` 和 `patterns.md`
- 生成前避免典型误写：读取 `anti-patterns.md`
- 排错：读取 `errors.md`
- 输出前自检：读取 `checklist.md`
- 需要确认真实类、接口、数据对象定义：先读 `源码类索引.md`，再按需读取 `assets/source/`
