# GPF HTTP 接口资料索引

## 推荐读取顺序

1. `overview.md`
2. `core-concepts.md`
3. `workflow.md`
4. `patterns.md`
5. `errors.md`
6. `checklist.md`

## 按任务选资料

- 判断组件和任务边界：读取 `overview.md`
- 判断路径、实现类、分发器关系：读取 `core-concepts.md`
- 生成代码：读取 `workflow.md` 和 `patterns.md`
- 排错：读取 `errors.md`
- 输出前自检：读取 `checklist.md`

## 源码快照

- 需要查看 `HttpRequestHandler`、`HttpResponseHandler`、`HandlerInterceptor`、`RequestMappingContext` 等框架定义时，读取 `assets/source/`
- 该目录只收敛当前技能执行所需的最小必要源码，避免依赖技能目录外的工程文档或源码路径

## 按问题查示例

- 需要最小接口声明结构：看 `assets/examples/basic_user_mapping.java`
- 需要 `RequestMappingContext` 和 `$context$`：看 `assets/examples/context_mapping.java`
- 需要分发器和拦截器挂载方式：看 `assets/examples/user_dispatcher_mapping_builder.java`
- 需要自定义 `HttpRequestHandler`：看 `assets/examples/custom_http_request_handler.java`
- 需要自定义 `HttpResponseHandler`：看 `assets/examples/custom_http_response_handler.java`
- 需要自定义 `HandlerInterceptor`：看 `assets/examples/custom_handler_interceptor.java`
- 需要系统默认处理器的装配方式：看 `assets/examples/default_handler_components_builder.java`
- 需要文件上传下载：看 `assets/examples/file_mapping.java`
- 需要 JWT 登录和鉴权：看 `assets/examples/jwt_auth_mapping.java`
- 需要 SSE 实时推送和 `Flux<SSEMessage>`：看 `assets/examples/sse_mapping.java`
